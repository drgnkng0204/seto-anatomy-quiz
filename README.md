# 瀬藤分 解剖学クイズ

iPhone / iPad のブラウザで使う、解剖学(瀬藤担当分)の問題演習アプリです。

- ユーザー(ユーザー1、2…)を選んで開始。成績はクラウド(Firebase Firestore)に保存され、ユーザー同士を比較できます。
- 問題はランダム出題。選択式は選ぶと即判定、記述式は「答えを表示」→「正解／不正解」を自己判定。
- 不正解の問題は **2回正解すると正解扱い** になります。
- 始め方: **つづきから**(解答済みの問題はスキップ) / **初めから**(全問) / **不正解の復習**。
- ホーム画面に追加(共有ボタン → ホーム画面に追加)するとアプリのように使えます。

## 更新方法

問題は `questions.txt` / `figure_questions.txt`(リポジトリ外の作業フォルダ)から `build_app.py` で `data.js` と `figs/` を生成します。
問題IDは問題文のハッシュなので、問題を追加・並べ替えても既存の記録は保たれます(問題文を書き換えると、その問題の記録だけ未回答に戻ります)。

## Firebase

- プロジェクト: `anatomy-quiz-d00f3c`(既存の「解剖過去問クイズ」と共用)
- コレクション: `seto_profiles`(名前・統計。誰でも読める) / `seto_records`(解答履歴。ユーザーIDを知っている人だけ取得可)
- ルールの反映: `firebase deploy --only firestore:rules --project anatomy-quiz-d00f3c`

認証なしの簡易方式です。ユーザーIDは端末内に保存されるランダム文字列で、知られない限り他人の履歴は読み書きされません。
